# TIR temporal entrypoint

This project begins from the Layer 0 decomposition already present in **The Fundamental Theory of Informational Relations (TIR)**.

The canonical entrypoint is the phase-relational Hamiltonian

\[
\hat H_s(\tau,k)=\hat H_{\mathrm{phase},s}(\tau,k)+\hat H_{\mathrm{rel},s}(\tau,k).
\]

The phase component is

\[
\hat H_{\mathrm{phase},s}(\tau,k)=
\frac{\hbar}{\Delta\tau_k}\rho_s(k)
\left[\kappa\hat W_s+\delta\hat{\mathcal I}_0(\tau)\right],
\]

while the relational/geometric component is

\[
\hat H_{\mathrm{rel},s}=
\frac12 g_{\mathrm{FS}}^{ab}\hat\Pi_a\hat\Pi_b+V_s.
\]

The temporal monograph takes the first branch as its starting object and develops its consequences independently before any spacetime recombination.

## Canonical constant

\[
\kappa=\frac{\ln 2}{24\pi}.
\]

The project therefore inherits from TIR the Shannon-information and Berry/phase-geometric foundation without duplicating the full particle-sector derivation.

## Separation rule

For the purpose of this monograph, the derivation is organized as

\[
\mathrm{TIR}
\longrightarrow
\begin{cases}

\text{spatial/relational geometry}.
\end{cases}
\]

The present repository develops the **temporal dynamics** branch. Spatial mechanics is retained as an external comparison/closure branch and is reintroduced only when the temporal construction is combined with relativistic spacetime.
