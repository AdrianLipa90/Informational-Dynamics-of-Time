# Initial temporal formalism

## 1. Informational constant

The canonical informational constant is inherited from TIR:

\[
\kappa=\frac{\ln 2}{24\pi}.
\]

## 2. Temporal state

Let the temporal state of the system be

\[
\Sigma_T(\tau)
\]

with evolution generated by the temporal/phase branch of the TIR Hamiltonian.

A minimal transport operator is written

\[
U_T(\Delta\tau)=\exp\left(-\frac{i}{\hbar}\hat H_T\Delta\tau\right).
\]

For reversible/unitary sectors,

\[
U_T^{-1}(\Delta\tau)=U_T^\dagger(\Delta\tau).
\]

This provides the formal distinction between forward state transport and backward state reconstruction.

## 3. Temporal wave domains and NOW localization

Define

\[
\Psi_-(\tau)
\]

as the past-directed reconstructive domain and

\[
\Psi_+(\tau)
\]

as the future-directed admissible domain.

The localized present event is

\[
N:=\mathrm{NOW}.
\]

The first temporal relation is

\[
\Psi_-\longrightarrow N\longrightarrow\Psi_+.
\]

The bifurcation operator is

\[
\mathcal B_N(\Psi_{\mathrm{in}})
=
\{\Psi_{\mathrm{out}}^{(1)},\Psi_{\mathrm{out}}^{(2)},\ldots\}.
\]

The realized history is represented by an admitted lineage

\[
R_0\prec R_1\prec\cdots\prec R_N,
\]

while future branches remain represented as admissible alternatives until a realization/admission event occurs.

## 4. Recall and retrodiction

Define recall as backward reconstruction over a realized lineage:

\[
\operatorname{RECALL}(R_k)
=
\operatorname{TRACE}^{-}(R_N\to R_k).
\]

Retrodiction is defined as inference or reconstruction of prior state from later evidence:

\[
\operatorname{RETRODICT}(\Sigma_N)
\mapsto
\{\Sigma_{N-1}^{(i)}\}.
\]

A retrocausal hypothesis requires a stronger test: a later boundary condition must alter statistics of an earlier observable after ordinary causal channels, leakage, synchronization artifacts, and post-selection effects have been controlled.

## 5. Temporal phase transport

For an energy eigencomponent,

\[
\Delta\phi_t=-\frac{E\,\Delta t}{\hbar}.
\]

The spatial comparison branch carries

\[
\Delta\phi_x=\frac{\mathbf p\cdot\Delta\mathbf x}{\hbar}.
\]

The relativistic closure target is therefore

\[
\Delta\phi
=
\frac{1}{\hbar}
\left(
\mathbf p\cdot\Delta\mathbf x-E\Delta t
\right).
\]

## 6. Spatial-offset divergence

For two nearby trajectories,

\[
\Delta\mathbf x(t)=\mathbf x_1(t)-\mathbf x_2(t).
\]

Define a spatial-offset rate

\[
D_x(t)=\frac{d}{dt}\Delta\mathbf x(t).
\]

and the associated phase-offset transport

\[
\Delta\phi_x
=
\frac{\mathbf p\cdot\Delta\mathbf x}{\hbar}.
\]

The spacetime phase-offset object used at closure is

\[
\Delta\phi
=
\frac{1}{\hbar}
\left(
\mathbf p\cdot\Delta\mathbf x-E\Delta t
\right).
\]

Every result should be labeled by one of the following evidence classes:

- `DEFINITION`
- `ALGEBRAIC_CONSEQUENCE`
- `COMPUTATIONAL_DEMONSTRATION`
- `STANDARD_PHYSICS_CLOSURE`
- `EXPERIMENTAL_HYPOTHESIS`
- `MEASURED_PHYSICAL_RESULT`

This separation is normative for the repository.
