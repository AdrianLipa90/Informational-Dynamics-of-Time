# Informational-Dynamics-of-Time

Research programme for deriving temporal dynamics from relational information and phase structure, and only at the final closure stage coupling the independently derived temporal branch to spatial structure.

## Repository architecture

The project has three parallel spines:

- **FORMALISM** — canonical equations, typed operators and dependency graph;
- **EVIDENCE** — append-only experiment runs, validation receipts, manifests and audits;
- **MONOGRAPH** — LaTeX narrative compiled from the formalism/evidence state.

The canonical dependency chain is:

`TIR -> Temporal Primitive -> Temporal Wave -> NOW -> Bifurcation -> Temporal Transport -> Memory -> Retrodiction -> Retrocausal Tests -> Einstein Closure`

The current admitted frontier is **Causal Bifurcation**. Existing memory/internal-elapsed constructions are retained as provisional downstream branches until their upstream gates close.
