\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This work develops a research programme in which temporal dynamics are derived from informational structure before spacetime geometry is introduced. The starting point is a relational state carrying a Shannon probability distribution and a normalized complex representative. Directed transitions carry both an exact Shannon entropy difference and a geometric phase link. Their combination is used to construct an auditable temporal transition phase, while closed-cycle identities separate exact state-function changes from genuinely non-exact directional information.

The central methodological objective is to determine which temporal properties arise from this dynamics without being inserted as primitive assumptions. These include ordered evolution, phase transport, chirality, scaling structure, event localization, causal bifurcation, memory, subjective temporal accumulation, and later metric calibration. Spatial structure is introduced only after the temporal branch has been independently developed, at which point compatibility with relativistic phase relations and Einstein closure becomes a final problem rather than an input assumption.

Formal derivation, computational evidence, and physical claim status are maintained as separate layers. Candidate relations enter the framework through typed definitions, counterexample analysis, reference tests, and explicit claim/equation registries. Visual representations are generated downstream from the same equations and code used in the computational layer.
