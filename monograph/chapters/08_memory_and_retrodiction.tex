\section{Memory as an oriented orbit coordinate}

Assign to each admitted relational state a complex memory coordinate
\[
m(s)=x_M(s)+iy_M(s)=r_M(s)e^{i\theta_M(s)}.
\]
The first oriented edge functional is
\[
\boxed{
A^{(M)}_{ab}
=\lambda_M\operatorname{Im}[m(a)^*m(b)]
=\lambda_M r_a r_b\sin(\theta_b-\theta_a).
}
\]
It is antisymmetric under edge reversal. Consequently it can supply the directional edge drive of the relational kinetic pair without modifying the symmetric density/viscosity mobility.

For a closed polygonal memory orbit,
\[
\sum_C A^{(M)}_e
=2\lambda_M\mathcal A_M(C),
\]
where \(\mathcal A_M(C)\) is the signed area enclosed by the orbit in the memory plane. Reversing orientation reverses the sign of the circulation. A degenerate orbit on one ray through the origin has zero circulation.

Through the transition-affinity relation,
\[
\sigma^{(M)}_{ab}=\frac{A^{(M)}_{ab}}{\ln2},
\]
so an oriented memory loop is a concrete candidate source of non-exact path affinity. This establishes a mathematical bridge between memory-orbit geometry and directed transition structure. The later interpretation of this object as physical memory, retrodiction, or subjective temporal experience remains a separate evidence problem.
