\chapter{ORCHORBITAL Attractors on Temporal Memory}

The temporal-memory branch now supports a first typed ORCHORBITAL attractor layer. The construction consumes the already defined memory phase state
\[
X_M=(m,v_M,\tau_{\rm int},\mathcal A_M)
\]
and a finite family of attractors
\[
\mathfrak A_i=(c_i,\mu_i),
\qquad \mu_i>0.
\]

\section{Binding field}

Relative to attractor \(i\), define
\[
\boxed{
E_i=\frac12\|v_M\|^2-\frac{\mu_i}{\|m-c_i\|}
}
\]
and positive binding margin
\[
\boxed{b_i=[-E_i]_+.}
\]
For positive total binding \(B=\sum_i b_i\), the attractor weights are
\[
\boxed{w_i=\frac{b_i}{B}},
\qquad
\sum_iw_i=1,
\]
and the active reference basin is the maximizing weight. Exact ties are resolved deterministically for replay stability.

If \(B=0\), the state receives the explicit \texttt{LEAK\_MODE} branch status. The v0.1 reference operator treats this as a fail-closed orbital admission boundary.

\section{Shannon basin organization}

The normalized weights form an instantaneous relational distribution over the bound basins. Their Shannon entropy is
\[
\boxed{
H_A=-\sum_{i:w_i>0}w_i\log_2w_i.
}
\]
For \(N>1\), the associated normalized attractor coherence is
\[
\boxed{
C_A=1-\frac{H_A}{\log_2N}.
}
\]
A symmetric two-attractor reference state therefore has \(H_A=1\) bit and \(C_A=0\), while concentration into one basin drives the coherence toward unity.

\section{Active-centre orbital dynamics}

On an admitted smooth segment with active attractor \(a\), the memory orbit is translated to the active centre and obeys
\[
\boxed{
\frac{d^2m}{d\tau_{\rm int}^2}
=-\mu_a\frac{m-c_a}{\|m-c_a\|^3}.
}
\]
This preserves the single-centre Kepler--Newton reference law on each smooth segment while allowing the basin field to be re-evaluated at the segment boundary.

The winding increment around the active centre is
\[
\boxed{
\Delta W_a
=\frac{1}{2\pi}
\operatorname{wrap}_{(-\pi,\pi]}
\left[
\arg(m_{n+1}-c_a)-\arg(m_n-c_a)
\right].
}
\]
After propagation the complete attractor field is evaluated again. A different maximizing basin is recorded as an attractor-switch candidate for the following segment.

\section{Memory-kick invariant of the active basin}

At fixed memory position define
\[
u_i=\frac{\mu_i}{\|m-c_i\|},
\qquad
T=\frac12\|v_M\|^2.
\]
Then
\[
\boxed{b_i=[u_i-T]_+.}
\]
An instantaneous Memory event changes velocity while leaving every \(u_i\) fixed. Whenever the post-event state remains bound, the maximizing basin is therefore
\[
\boxed{
\arg\max_i b_i=\arg\max_i u_i,
}
\]
independent of the velocity-only kick. Such a kick can change the normalized basin weights and their Shannon observables, or drive all margins to zero and enter \texttt{LEAK\_MODE}; it does not switch the winning bound attractor at fixed position.

The deterministic reference probe recorded zero active-attractor changes in 2998 before/after bound comparisons, while the normalized basin weights changed in all 2998 comparisons.

\section{Persisted ORCHORBITAL lineage cell}

The transport-derived Memory receipt is
\[
\mathcal E_n=(\Delta\tau_n,q_n,\delta m_n).
\]
The event kick is applied before the active-centre smooth segment. Exact ledger-assisted inversion persists the attractor snapshot actually used by the segment:
\[
\boxed{
\mathcal O_n=(\mathcal E_n,a_n,c_{a_n},\mu_{a_n}).
}
\]
The forward and inverse cells are
\[
\boxed{
X_{n+1}=\Phi_{a_n}(\Delta\tau_n)K_{\mathcal E_n}X_n,
}
\]
\[
\boxed{
X_n=K_{\mathcal E_n}^{-1}\Phi_{a_n}^{-1}(\Delta\tau_n)X_{n+1}.
}
\]
The centred inverse translates to the persisted active centre, applies the existing algebraic inverse of the Memory velocity-Verlet segment, and translates back before removing the recorded event kick.

A 500-trajectory, six-cell deterministic probe returned a maximum complete-lineage reconstruction defect below \(9.3\times10^{-16}\). Replacing the persisted active attractor by a different valid centre/coupling produced a reconstruction error of approximately \(1.78\times10^{-2}\), establishing the active-attractor snapshot as required lineage provenance.

\section{Residence time and attractor transition graph}

For a multi-segment trajectory, the active attractor of every completed segment is recorded. For attractor \(i\), define its internal residence time
\[
\boxed{
T_i^{\rm res}
=\sum_{n:a_n=i}\Delta\tau_{{\rm int},n}
}
\]
and accumulated winding
\[
\boxed{
W_i^{\rm tot}
=\sum_{n:a_n=i}\Delta W_{i,n}.
}
\]

Adjacent segment labels define a directed attractor-transition count
\[
\boxed{
N_{i\to j}
=\#\{n:a_n=i,\ a_{n+1}=j,\ i\neq j\}.
}
\]
The resulting directed graph is an appendable summary of which memory basins the temporal trajectory occupies, for how much internal elapsed activity, and through which ordered switches it moves.

\section{Closure observable}

With declared position and velocity scales \(r_*>0\) and \(v_*>0\), the reference phase-space closure defect is
\[
\boxed{
D_{\rm cl}
=
\sqrt{
\left(\frac{\|m_f-m_i\|}{r_*}\right)^2
+
\left(\frac{\|v_f-v_i\|}{v_*}\right)^2
}.
}
\]
The normalization scales remain explicit inputs to the observable.
