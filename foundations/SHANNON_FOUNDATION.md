# Shannon Foundation

For a relational probability state \(p(s)=(p_1,\ldots,p_n)\), the canonical information observable is

\[
H_S(s)=-\sum_i p_i(s)\log_2 p_i(s).
\]

For an admitted transition \(e:a\to b\),

\[
\Delta H_e=H_S(b)-H_S(a).
\]

Because \(\Delta H\) is an exact state-function difference, it telescopes on every closed directed
cycle. Non-zero cycle information therefore requires an explicitly non-exact edge quantity, kept
separate in the formalism as the directed affinity \(\sigma_e\).
