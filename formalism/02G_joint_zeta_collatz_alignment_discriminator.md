Status: `CANDIDATE / LOW_PRIME_ALIGNMENT_WITNESS / BULK_WINDOW_STABILITY_FAIL`

02F established a sparse Zeta-ordered nearest-frame path and a controlled low-mode continuum limit. ## 1. Two centered operators

For an ordered prime window

\[
p_1<\cdots<p_N,
\]

define the centered Zeta-frequency operator

\[
\boxed{
D_\zeta
=\operatorname{diag}(\ln p_k-\langle\ln p\rangle).
}
\]

From 02F, consecutive prime frames carry first-merge mobilities

\[
M_k=\frac{1}{1+d_C(p_k,p_{k+1})}.
\]

On the same finite path, let

\[
K_C=D^\dagger\operatorname{diag}(M_k)D
\]

with unit edge spacing for the alignment diagnostic. Remove the trace component,

\[
\widetilde K_C
=K_C-\frac{\operatorname{tr}K_C}{N}I.
\]

Normalize both operators by their Frobenius norms,

\[
\widehat D_\zeta
=\frac{D_\zeta}{\|D_\zeta\|_F},
\qquad
\widehat K_C
=\frac{\widetilde K_C}{\|\widetilde K_C\|_F}.
\]

The balanced diagnostic Hamiltonian is

\[
\boxed{
H_{\rm joint}=\widehat D_\zeta+\widehat K_C.
}
\]

This normalization removes the arbitrary relative scale from the structural discriminator; it is a diagnostic normalization rather than a physical calibration of the 02E coupling constant.

## 2. Marginal-preserving alignment statistic

Define

\[
\boxed{
A_{\zeta C}
=\left\|[\widehat D_\zeta,\widehat K_C]\right\|_F.
}
\]

For a nearest-neighbor path this statistic is sensitive to how the edge mobilities are paired with the neighboring Zeta-frequency differences. A null ensemble is generated by permuting the same mobility vector while holding the prime-frequency sequence fixed.

Therefore each null preserves:

```text
same prime frequency marginal
same Collatz mobility marginal
same path size
same number of local couplings
```

and destroys only the original edge-by-edge Zeta–Collatz alignment.
