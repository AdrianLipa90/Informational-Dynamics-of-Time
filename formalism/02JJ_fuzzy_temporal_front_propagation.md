# 02JJ — Fuzzy Temporal Front Propagation

Status: `FORMAL_CANDIDATE / LOCAL_PATH_FRONT_GATE`

02JI defines the dimensionless genuine fuzzy-interface strength

\[
F_n=g_n\cos^2\!\frac{\delta_n}{2},
\qquad
0\le F_n\le1.
\]

This layer adds the occupancy-sensitive interface weight required to distinguish a physically occupied fuzzy seam from a formally balanced but negligibly populated pair, and derives the short-\(\Theta\) propagation hierarchy generated by a nearest-neighbour Schrödinger frame Hamiltonian.

## 1. Raw fuzzy-interface weight

For neighbouring frame amplitudes

\[
a_n=r_ne^{i\alpha_n},
\qquad
a_{n+1}=r_{n+1}e^{i\alpha_{n+1}},
\]

and seam mismatch

\[
\delta_n=\alpha_{n+1}-\alpha_n-\varphi_n,
\]

define the pair weight

\[
w_n=r_n^2+r_{n+1}^2.
\]

The occupancy-sensitive fuzzy-interface weight is

\[
\boxed{
J_n:=w_nF_n
=2r_nr_{n+1}\cos^2\!\frac{\delta_n}{2}.
}
\]

Hence

\[
J_n=0
\]

when either neighbouring frame is unoccupied, and also for the exact anti-phase seam control \(\delta_n=\pi\).

For a phase-locked seam,

\[
\delta_n=0,
\]

we obtain

\[
\boxed{J_n^{\rm lock}=2r_nr_{n+1}.}
\]

Thus \(F_n\) measures the quality of a two-frame interface while \(J_n\) additionally measures whether that interface carries actual amplitude weight.

## 2. Local path Hamiltonian

Let \(N\) frames be ordered on the half-frame path and let the intrinsic Schrödinger evolution be

\[
\boxed{
i\frac{d\psi}{d\Theta}=H\psi,}
\]

where \(H=H^\dagger\) is nearest-neighbour/tridiagonal,

\[
H_{jk}=0\qquad\text{for }|j-k|>1,
\]

and every path coupling is nonzero,

\[
h_n:=H_{n+1,n}\ne0.
\]

Take the sharp initial frame

\[
\boxed{\psi(0)=|1\rangle.}
\]

The unitary series is

\[
\psi(\Theta)
=\sum_{m=0}^{\infty}
\frac{(-i\Theta)^m}{m!}H^m|1\rangle.
\]

On a nearest-neighbour path, graph distance gives

\[
(H^m)_{n1}=0
\qquad\text{for }m<n-1.
\]

At the first admitted power,

\[
\boxed{
(H^{n-1})_{n1}=\prod_{j=1}^{n-1}h_j.
}
\]

Therefore the frame amplitude has the short-time expansion

\[
\boxed{
a_n(\Theta)
=
\frac{(-i\Theta)^{n-1}}{(n-1)!}
\prod_{j=1}^{n-1}h_j
+O(\Theta^n).
}
\]

The diagonal Zeta generator may change the higher-order coefficients but cannot shorten this graph-distance order.

## 3. Odd-power fuzzy-front hierarchy

On the locked seam, combine the neighbouring leading amplitudes:

\[
J_n^{\rm lock}=2|a_n||a_{n+1}|.
\]

Using the path-distance expansion,

\[
\boxed{
J_n^{\rm lock}(\Theta)
=
C_n|\Theta|^{2n-1}
+O(|\Theta|^{2n}),
}
\]

with

\[
\boxed{
C_n=
\frac{2}{(n-1)!n!}
\left(\prod_{j=1}^{n-1}|h_j|^2\right)|h_n|>0.
}
\]

Hence the successive fuzzy seams have leading orders

\[
\boxed{
|12|:O(|\Theta|),
\quad
|23|:O(|\Theta|^3),
\quad
|34|:O(|\Theta|^5),
\quad\ldots
}
\]

or generally

\[
\boxed{J_n=O(|\Theta|^{2n-1}).}
\]

This is the local fuzzy-front theorem for a sharp boundary frame on a connected nearest-neighbour temporal path.

## 4. Zeta–Collatz path realization

02F supplies the positive first-merge mobilities

\[
M_n=\frac{1}{1+d_C(p_n,p_{n+1})}>0
\]

and the weighted nearest-neighbour path Laplacian \(L_C^{\rm path}\). A local candidate Hamiltonian is

\[
\boxed{
H_{\zeta C}^{\rm path}
=\alpha_\zeta\widetilde D_\zeta
+g_C L_C^{\rm path}.
}
\]

For \(g_C\ne0\), every admitted path edge has nonzero coupling. Therefore the graph-distance theorem applies directly to the Zeta-ordered first-merge Collatz path.

The prime-specific physical status remains governed by the null/discriminator gates already recorded in 02F--02I.

## 5. Onsager phase-locking contribution

02JG gives, at fixed neighbouring magnitudes,

\[
D_\Theta F_n\ge0.
\]

Since \(w_n\) is fixed under that phase-only subflow,

\[
\boxed{
D_\Theta J_n
=w_nD_\Theta F_n\ge0.
}
\]

Thus the two mechanisms have distinct typed roles:

```text
Schrodinger path transport -> creates spatially adjacent co-occupancy
Onsager seam descent       -> raises phase coherence of occupied neighbors
J_n                         -> occupancy-sensitive fuzzy-interface weight
```

For the fully coupled system, 02JH remains authoritative:

\[
\frac{dV_{\rm seam}}{d\Theta}=P_H-D_\alpha.
\]

No unconditional monotonicity of the full fuzzy-front profile is asserted.

## 6. Front observables

For the edge profile

\[
\mathbf J=(J_1,\ldots,J_{N-1}),
\]

define the total fuzzy-interface weight

\[
\boxed{J_{\rm tot}=\sum_{n=1}^{N-1}J_n}
\]

and, when \(J_{\rm tot}>0\), the interface barycentre

\[
\boxed{
\bar n_F
=\frac{\sum_{n=1}^{N-1} nJ_n}{J_{\rm tot}}.
}
\]

These are diagnostics only. The exact front statement is the graph-distance/odd-power hierarchy above and requires no arbitrary activation threshold.

## 7. Falsification gates

Reference tests require:

- exact identity \(J_n=(r_n^2+r_{n+1}^2)F_n=2r_nr_{n+1}\cos^2(\delta_n/2)\);
- exact zero for a missing neighbour and for the anti-phase control;
- exact path-power zeros \((H^m)_{n1}=0\) for \(m<n-1\);
- exact nonzero first path coefficient \((H^{n-1})_{n1}=\prod h_j\);
- predicted interface orders \(1,3,5,\ldots,2N-3\);
- finite unitary reference ratios consistent with the predicted short-time powers;
- direct application to the positive Zeta-ordered first-merge Collatz path.
