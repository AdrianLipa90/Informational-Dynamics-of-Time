# 00C — Relational Density, Viscosity, and Directed Kinetics

Status: `FORMAL_CANDIDATE_WITH_PROVED_STRUCTURAL_IDENTITIES`

This layer asks what the scalar relational density field \(\rho_R\) and relational viscosity field \(\eta_R\) can do at the first transition-kinetic level without inserting a temporal arrow by hand.

Let every admitted state carry strictly positive scalars
\[
\rho_R(s)>0,
\qquad
\eta_R(s)>0.
\]
For an undirected pair \(\{a,b\}\), define a symmetric pair mobility
\[
\boxed{
M_{ab}
=
\frac{\sqrt{\rho_R(a)\rho_R(b)}}
{\tfrac12[\eta_R(a)+\eta_R(b)]}.
}
\]
Then \(M_{ab}=M_{ba}>0\). Density increases the available relational mobility, while viscosity suppresses it.

Introduce a dimensionless antisymmetric edge drive
\[
A_{ab}=-A_{ba}.
\]
The minimal positive directed rates are
\[
\boxed{
W_{a\to b}=M_{ab}e^{A_{ab}/2},
\qquad
W_{b\to a}=M_{ab}e^{-A_{ab}/2}.
}
\]
The path affinity becomes
\[
\boxed{
\sigma_{a\to b}
=
\log_2\frac{W_{a\to b}}{W_{b\to a}}
=
\frac{A_{ab}}{\ln2}.
}
\]

## Theorem T009 — scalar mobility does not create directional affinity

Because the same positive mobility factor multiplies both directions,
\[
\frac{W_{a\to b}}{W_{b\to a}}=e^{A_{ab}},
\]
so \(M_{ab}\), and therefore the symmetric scalar density/viscosity contribution contained in it, cancels exactly from the forward/reverse ratio.

Thus scalar density and viscosity can control transition pace without by themselves selecting transition direction in this minimal symmetric construction.

## Theorem T009A — exact scalar drive gives zero cycle affinity

If the edge drive is generated by a scalar state potential \(V_R\),
\[
A_{ab}=V_R(b)-V_R(a),
\]
then on every closed cycle
\[
\sum_{e\in C}A_e=0,
\qquad
\mathcal A_C=0.
\]
Therefore any arrow-producing circulation requires a non-exact edge drive, an enlarged state carrying memory/history, or another mechanism whose circulation does not reduce to a scalar state-function difference.

## Consequence for the temporal programme

The first clean separation is now
\[
\boxed{
(\rho_R,\eta_R)\to M_{ab}\quad\text{(pace/mobility)},
\qquad
A_{ab}\to\sigma_{ab}\quad\text{(directional affinity)}.
}
\]
This makes the next dependency precise: investigate whether memory-orbit state, phase holonomy, or another admitted relational structure generates a non-exact \(A_{ab}\) while \(\rho_R\) and \(\eta_R\) regulate the rate at which that directed transition is realized.
