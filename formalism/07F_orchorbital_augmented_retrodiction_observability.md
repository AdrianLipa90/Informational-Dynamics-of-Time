# 07F — ORCHORBITAL-Augmented Retrodiction Observability

Status: `PROVISIONAL_DOWNSTREAM_CANDIDATE / ORCHORBITAL_OBSERVABILITY_TARGETED_PASS`

This layer consumes the persisted Memory→ORCHORBITAL lineage and separates two measurement cases: a fully retained Memory phase-state checkpoint and a partial checkpoint supplemented by ORCHORBITAL observables.

## 1. Full checkpoint closure

Let
\[
X=(r_x,r_y,v_x,v_y)\in\mathbb R^4
\]
be a retained Memory checkpoint and let a continuous ORCHORBITAL observable vector be
\[
O=f(X),
\]
for example the bound-basin weights \(w=(w_1,\ldots,w_N)\).

For latent event coordinates \(z\),
\[
J_X=\frac{\partial X}{\partial z},
\qquad
J_O=\frac{\partial O}{\partial z}.
\]
Inside one fixed attractor/support regime the chain rule gives
\[
\boxed{J_O=Df(X)J_X.}
\]
Consequently
\[
\boxed{
\operatorname{rank}
\begin{pmatrix}J_X\\J_O\end{pmatrix}
=\operatorname{rank}J_X.
}
\]
Thus the continuous ORCHORBITAL rows lie in the first-order row space already generated by a fully retained phase-state checkpoint.

The deterministic 500-case probe returned identical full-checkpoint rank before and after adding basin weights in all 500 cases. The maximum numerical residual of the weight Jacobian outside the row space of the full-state Jacobian was
\[
3.457720719261408\times10^{-16}.
\]
An independent replay returned
\[
3.619705363875762\times10^{-16}.
\]

## 2. Partial checkpoints

Let a partial checkpoint be
\[
Y_P=PX
\]
for a projection \(P\). The augmented measurement is
\[
Y_{P,O}=(PX,f(X))
\]
with Jacobian
\[
\boxed{
J_{P,O}=
\begin{pmatrix}
P J_X\\Df(X)J_X
\end{pmatrix}.
}
\]
Its first-order rank obeys
\[
\operatorname{rank}J_{P,O}\le\operatorname{rank}J_X.
\]
Within that bound the ORCHORBITAL rows can restore directions removed by the projection \(P\).

For the tested two-kick reference with four latent coordinates, one final checkpoint retaining
\[
(r_x,r_y,v_x)
\]
had rank three. Adding the three basin weights raised the local rank to four in 500/500 deterministic nearby cases.

For a position-only checkpoint
\[
(r_x,r_y),
\]
the rank changed from two to three in 500/500 cases and therefore retained one unresolved local latent direction.

## 3. Kinetic channel carried by basin weights

At fixed position define
\[
u_i=\frac{\mu_i}{r_i},
\qquad
T=\frac12(v_x^2+v_y^2).
\]
Inside a fixed positive-support regime,
\[
b_i=u_i-T,
\qquad
w_i=\frac{u_i-T}{\sum_j(u_j-T)}.
\]
The basin-weight Jacobian therefore carries sensitivity to the scalar kinetic channel \(T\). When position and one velocity component are retained, this channel can restore the local derivative direction associated with the omitted component whenever the corresponding derivative is nonzero.

Local rank supports a same-regime local reconstruction claim. Global sign-reflection structure is handled by the separate 07G global-null gate.

## 4. Active-basin labels and switching boundaries

The discrete active-attractor label is piecewise constant inside a basin interior, so its regular differential contribution there is zero. Switching, support-entry and `LEAK_MODE` surfaces are non-smooth boundaries of the observation map.

The reference finite-difference implementation records the active-attractor sequence and bound-support pattern. A plus/minus perturbation that changes either signature receives the fail-closed boundary status instead of a regular Jacobian.
