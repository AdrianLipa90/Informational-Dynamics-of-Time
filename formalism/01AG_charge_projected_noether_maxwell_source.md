## 1. Charged flavour multiplet

Let

\[
\Psi(x)\in\mathbb C^N
\]

be a local complex flavour multiplet and let `Q=Q^\dagger` be its electric-charge operator. Use the synchronized IDT/RFC gauge convention

\[
\boxed{
\Psi' = e^{iQ\Lambda/\hbar}\Psi,
\qquad
A' = A-d\Lambda.
}
\]

The gauge-covariant derivative is

\[
\boxed{
\mathcal D_\mu\Psi
=\nabla_\mu\Psi+rac{i}{\hbar}A_\mu Q\Psi.
}
\]

Then

\[
(\mathcal D_\mu\Psi)'
=e^{iQ\Lambda/\hbar}\mathcal D_\mu\Psi.
\]

## 2. Matter action and charge-compatibility gate

Admit the local quadratic matter sector

\[
\boxed{
\mathcal L_m
=(\mathcal D_\mu\Psi)^\dagger\mathcal D^\mu\Psi
-\Psi^\dagger\mathcal M^2\Psi
-V_{inv}(\Psi),
}
\]

where `V_inv` is gauge invariant. Gauge invariance of the flavour/mass operator requires

\[
\boxed{[\mathcal M^2,Q]=0.}
\]

This is the field-theory counterpart of the 01AF dynamical condition `[H_f,Q]=0`: flavour dynamics must preserve the electric-charge eigenspaces.

## 3. Charge-projected phase current

Define

\[
\boxed{
\mathcal J_Q^\mu
:=i\left[
(\mathcal D^\mu\Psi)^\dagger Q\Psi
-\Psi^\dagger Q\mathcal D^\mu\Psi
\right].
}
\]

For a single component with `Q=q`, this reduces to

\[
\boxed{
\mathcal J_Q^\mu=qJ_\vartheta^\mu,
}
\]

where the 01AC gauge-covariant phase current is

\[
J_\vartheta^\mu
=i\left[
\psi(\mathcal D^\mu\psi)^*
-\psi^*\mathcal D^\mu\psi
\right].
\]

## 4. Variation with respect to the AB potential

The dependence of `D_mu Psi` on `A_mu` is

\[
\delta_A(\mathcal D_\mu\Psi)
=\frac{i}{\hbar}Q\Psi\,\delta A_\mu,
\]

\[
\delta_A(\mathcal D_\mu\Psi)^\dagger
=-\frac{i}{\hbar}\Psi^\dagger Q\,\delta A_\mu.
\]

Therefore the matter variation is

\[
\delta_A\mathcal L_m
=\frac{1}{\hbar}\mathcal J_Q^\mu\delta A_\mu.
\]

Thus

\[
\boxed{
\frac{1}{\sqrt{-g}}\frac{\delta S_m}{\delta A_\mu}
=\frac{1}{\hbar}\mathcal J_Q^\mu.
}
\]

RF-M1 uses the Maxwell source convention

\[
S_{EM}\supset-\int d^4x\sqrt{-g}\,J_{EM}^\mu A_\mu.
\]

Accordingly the source current contributed by the charged matter sector is

\[
\boxed{
J_{EM}^\mu=-\frac{1}{\hbar}\mathcal J_Q^\mu.
}
\]

For one charge `q`,

\[
\boxed{
J_{EM}^\mu=-\frac q\hbar J_\vartheta^\mu.
}
\]

The coefficient is the same `q/hbar` that fixes the Aharonov–Bohm connection. No independent current-rescaling parameter appears at this interface.

\[
